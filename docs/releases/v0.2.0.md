# beech v0.2.0

Search and editing release.

## Added

- Fuzzy search: `/` or `ctrl+f` opens the bottom input line, `Enter` jumps to
  the next match, and `n` / `N` cycle forward and backward. Matching is
  case-insensitive and accepts characters in order but not adjacent, using the
  same `sahilm/fuzzy` matcher as pine and spruce. Matches keep document order
  so cycling moves through the map top to bottom.
- Replace-style edit: `E` and `I` open the editor empty to replace a node's
  title in one step, following h-m-m.

## Fixed

- Fold changes are now undoable. Collapsing or expanding with `space`, and the
  automatic expand when navigating into a collapsed node, each form one undo
  transaction.
- The viewport is clamped when the terminal shrinks while editing, so the map
  keeps rendering instead of going blank.

## Internal

- Merged the duplicated `itoa` helpers into `strconv.Itoa`.
- Removed redundant slice clones in the document model.
