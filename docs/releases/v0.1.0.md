# beech v0.1.0

First public release of Beech, a keyboard-first terminal mind map for structured
Markdown notes.

## Highlights

- Compact left-to-right mind-map layout with spatial keyboard navigation
- Inline node creation and editing with live wrapping
- Add, cut, copy, paste, reorder, promote, and demote complete subtrees
- Collapse and expand branches with persisted fold state
- Undo and redo for document changes
- Contextual action feedback and explicit no-op messages
- Everforest structural colors and Markdown syntax highlighting
- Unicode and grapheme-aware terminal rendering

## Markdown and import

- Native tab-indented Markdown list format
- Hidden Markdown comments for format and collapsed-state metadata
- Strict validation that refuses unsupported Markdown instead of rewriting it
- One-way import of existing h-m-m `.hmm` files into new `.md` documents
- Imported legacy source files remain untouched

## Reliability

- Atomic same-directory file replacement
- Existing file permission preservation
- SHA-256 external-change detection before save
- Symlink target resolution
- Exact-width terminal frames and wide-grapheme handling
- Parent-relative layout that isolates unrelated branches
- `q` saves before quitting; `Q` discards changes and quits

## Installation

```sh
go install github.com/Thelost77/beech@v0.1.0
```

## Requirements

- Go 1.25 or newer for source installation
- A Unicode-capable terminal

Beech has no external runtime dependencies.

## Notes

Beech edits its strict outline subset rather than arbitrary Markdown documents.
This is the initial public release and active development will continue.
