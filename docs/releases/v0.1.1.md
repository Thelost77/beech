# beech v0.1.1

Editing-focused release.

## Changed

- Node titles are now edited on a full-width input line at the bottom of the
  screen, following h-m-m. The map keeps the committed layout and viewport
  while typing; the title and layout update once, on Enter. Esc cancels and
  restores the previous state.
- Long edit values scroll horizontally within the input line instead of
  wrapping inside the map.

## Removed

- Transient inline editing: per-keystroke edit layouts, dynamic node resizing,
  and the inline cursor layer. The map no longer reflows or scrolls while
  typing, which removes layout jitter around wrapped titles.
